This is a multi-purpose Discord bot built with Python. It features:

🎤 Text-to-Speech (multi-language)  
🧠 GPT-4o powered Q&A (`/ask`)  
🖼 AI Image Generator (`/generate_image`)  
🎮 Mini Games (`/roll_dice`, `/rps`, `/tictactoe`, etc.)  
📄 File and PDF generation
